# nimbus-edge / wake — the flash-in wake protocol

Plug the verified CNMB drive into this machine → the brain wakes: the nimbus-edge C daemons + the nimbus-local
gateway boot from the flash, and `ai.carnimbus.com` opens. Pull the drive → sleep: the local daemons tear down
(the site itself already auto-locks ~2.3s after unplug via its own heartbeat).

## Honest boundary
This runs the stack **locally / on your LAN**. It is NOT a public cutover: carnimbus.com stays on Cloudflare
(TLS, DDoS, PII). See `../MASTER-PLAN.md` for the gated path to ever serving public traffic from this stack.

## How it works
- `wake-launcher.sh` — a tiny launcher copied to `~/Library/Application Support/CarNimbus/` (internal disk);
  launchd's stable entry point. It hands off to the drive's `wake.sh` when the drive is mounted + readable.
- `wake.sh` — guards (is it our drive?), verifies (Ed25519 private key present on the drive, else fail closed),
  single-flight lock (StartOnMount + RunAtLoad can double-fire), boots the daemons idempotently, opens the door,
  spawns an unplug watcher.
- `sleep.sh` — kills the booted daemons by pidfile.
- `com.carnimbus.wake.plist` — the launchd agent (`StartOnMount` + `RunAtLoad`); the real one is generated by
  `install.sh` pointing at the local launcher. The copy in this folder is a reference.

## ⚠️ One manual step macOS forces (cannot be scripted)
A launchd agent may not exec code on — or even read files from — the **removable** CNMB drive until `/bin/bash`
has **Full Disk Access**. This is Apple's TCC privacy control; it cannot be granted from a script (that's the
point of it). `install.sh` opens the pane and tells you what to add:
> System Settings ▸ Privacy & Security ▸ Full Disk Access ▸ **+** ▸ `/bin/bash` ▸ toggle **ON**.

Until you grant it, the on-mount automation no-ops quietly. **The protocol still works right now** — trigger it
by hand any time (this needs no grant, your Terminal already has access):
```sh
bash /Volumes/CNMB/01-prod/01A-app/carnimbus-com-site/nimbus-edge/wake/wake.sh
```

## Install / uninstall
```sh
bash install.sh      # keygen if needed, build, install launcher + agent, open the FDA pane
bash uninstall.sh    # unload + remove launcher/agent; drive key and data untouched
```
Verify: `launchctl list | grep carnimbus.wake`, then check `run/wake.log`.
